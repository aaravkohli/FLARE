# Dataset Notes

## Default: Synthetic Data

The system trains on **synthetic RF metrics** generated by `simulation/generator.py`.
No real dataset is required to run in SIMULATION mode.

## Plugging in a Real Dataset

To use a real RF dataset, replace the `load_local_data()` function in `fl/client.py`
with a loader that reads your dataset.

### Expected Format

Your dataset should provide per-sample sequences with shape `[seq_len, 5]`:

| Feature Index | Feature      | Range        |
|---------------|--------------|--------------|
| 0             | RSSI (dBm)   | -120 to 0    |
| 1             | PDR          | 0 to 1       |
| 2             | SINR (dB)    | -10 to 30    |
| 3             | Latency (ms) | 0 to 1000    |
| 4             | Packet Loss  | 0 to 1       |

### Suggested Public Datasets

- **DroneRF** — RF signal dataset for drone detection (IEEE DataPort)
- **CRAWDAD** — Wireless trace archive (crawdad.org)
- **POWDER / ORBIT** — OpenFlow-capable RF testbeds

### Loading a CSV Dataset

```python
import pandas as pd
import numpy as np
import torch

def load_local_data_from_csv(path: str, seq_len: int = 10):
    df = pd.read_csv(path)
    # Columns: rssi, pdr, sinr, latency, packet_loss, label
    features = df[["rssi","pdr","sinr","latency","packet_loss"]].values.astype(np.float32)
    labels   = df["label"].values.astype(np.float32)
    # Build sliding windows
    X, y = [], []
    for i in range(len(features) - seq_len):
        X.append(features[i:i+seq_len])
        y.append(labels[i+seq_len])
    return torch.tensor(X), torch.tensor(y)
```
